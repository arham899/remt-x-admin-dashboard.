# REMT-X Admin Dashboard (early version)

> **➡️ This project now lives in [arham899/remt-x-dashboard.](https://github.com/arham899/remt-x-dashboard.)** — the full REMT-X system (Chrome extension + telemetry hub + supervisor dashboard) with docs and a [live demo](https://remt-x-admin-dashboard-kxet.vercel.app/).

This repo holds the first standalone version of the REMT-X supervisor dashboard: a React + TypeScript + Vite app (Tailwind, Recharts, Framer Motion) that receives live telemetry over Socket.io.

```bash
npm install
npm run dev
```
